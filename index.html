Integrasi firmware belum diaktifkan. N301 memiliki beberapa versi firmware, sehingga endpoint admin harus disesuaikan dengan router yang digunakan.

Langkah berikutnya

  1. Hubungkan HP/laptop ke Wi-Fi Tenda N301.
  2. Buka halaman admin router, biasanya 192.168.0.1.
  3. Catat versi firmware dan kirim screenshot halaman Status/Wireless.
  4. Setelah endpoint firmware diketahui, backend dapat diisi dengan kontrol SSID, client, block/unblock, dan restart.
